# Passeport élève Sigma F

Site statique (GitHub Pages) du passeport élève de l'association Sigma F.

- `index.html` : le passeport (mode démonstration avec des élèves fictifs « Exemple »).
- `voix/` : fichiers audio du site.

Aucune donnée réelle d'élève n'est stockée dans ce dépôt. Les vraies notes restent dans la base Sigma F
et ne sont envoyées qu'à l'élève qui saisit son code personnel (étape à venir).
